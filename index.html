1. Install TabungKita on your iPhone

Use it full-screen like a normal app.

1
Open in Safari

Open your TabungKita link in Safari (not Chrome).

2
Add to Home Screen

Tap Share (square with arrow) → Add to Home Screen → Add.

3
Launch from Home Screen

Open TabungKita from its icon. Your data is saved on this device.

2. Auto-log Apple Pay taps

Every Wallet payment is sent to TabungKita automatically.

1
Create Automation

Open Shortcuts → Automation → + → Transaction → pick your RHB card → Run Immediately.

2
Add "Open URLs" action

Use this URL, inserting the Amount and Merchant variables from the Shortcut Input:

https://YOUR-LINK/?amount=[Amount]&merchant=[Merchant]&method=Apple+Pay+(RHB+Visa)

3. Capture DuitNow QR & RHB screens (Back Tap)

Double-tap the back of your iPhone after paying.

1
Build the Shortcut

New Shortcut: Take Screenshot → Extract Text from Image → URL Encode → Open URLs:

https://YOUR-LINK/?quick_text=[Encoded Text]
2
Bind to Back Tap

Settings → Accessibility → Touch → Back Tap → Double Tap → choose your Shortcut.

3
Use it

After a DuitNow QR payment or opening your e-Penyata Gaji, double-tap the back of your phone.

4. Auto-log bank SMS

Forward RHB / FPX / DuitNow SMS alerts automatically.

1
Message Automation

Shortcuts → Automation → + → Message → Message Contains RM → Run Immediately.

2
Open URLs

URL-encode the message body, then open:

https://YOUR-LINK/?sms=[Encoded Message]

5. Sync across devices (Google Sheets + Gmail)

Optional — share data between phone and laptop.

1
Create a Sheet

Open sheets.new → Extensions → Apps Script → paste integrations/google-apps-script.gs.

2
Deploy

Deploy → New deployment → Web app (Execute as Me, Access: Anyone). Copy the URL.

3
Connect

Paste the URL in the Sync tab → Sync Now. Optionally add a 15-minute trigger for scanGmailForTransactions.
